# Роҳат — система управления рестораном

Учебный проект: заказы, склад, персонал и отчёты ресторана на одном кассовом компьютере.
PRD и роадмап лежат в `prd and roadmap/`.

**Стек:** Next.js 16 (App Router, server actions) · TypeScript · Tailwind CSS 4 · Prisma 6 + SQLite · Motion · Three.js (React Three Fiber + drei) · Lenis · Lucide.

## Запуск

```bash
npm install
cp .env.example .env      # и вписать SESSION_SECRET
npm run db:setup          # создать базу и залить начальные данные
npm run db:demo           # история продаж за 30 дней (по желанию)
npm run dev               # http://localhost:3000
```

Сайт для гостей — http://localhost:3000, система — http://localhost:3000/login.
Демо-вход: **владелец — 1111**, **кассир — 2222**.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Запуск для разработки |
| `npm run db:migrate` | Применить изменения `prisma/schema.prisma` |
| `npm run db:seed` | Залить начальные данные (меню, склад, сотрудники, столы) |
| `npm run db:demo` | Сгенерировать историю продаж за 30 дней (для отчётов и зарплаты) |
| `npm run db:reset` | Удалить базу и создать заново с демо-данными |
| `npm run db:studio` | Посмотреть базу в браузере |

## Устройство

- `app/page.tsx` + `components/site/` — сайт для гостей на главной `/`: меню с фото и ценами, корзина, заказ доставки с картой (OpenStreetMap + Nominatim), бронь стола, отзывы, контакты. Заявки с сайта ждут кассира в разделе «Заявки с сайта» (`app/(app)/requests`), подтверждённые становятся обычным заказом или бронью. Данные ресторана (адрес, часы, доставка) — `lib/site.ts`.
- `app/(app)/…` — разделы после входа (зал, заказы, касса, меню, склад, персонал, отчёты).
- `app/login` — вход по пин-коду.
- `app/actions` — серверные действия (всё, что меняет данные).
- `lib/` — база, сессия, журнал действий, деньги, переводы RU / TJ.
- `components/` — дизайн-система «Чайхана вечером»: кнопки, карточки, орнамент сюзане.
- `components/three/` — 3D: зал (переключатель 2D / 3D в «Зале»), чайник на экране входа, облёт зала на `/about`. Геометрия в коде, без загрузки моделей; без WebGL, при «уменьшить движение» или если стабильно меньше 30 кадров/с — откат на 2D / орнамент.
- `app/about` — экран «О проекте» для защиты, открывается и без входа.

## Правила

- Деньги — в дирамах (целые числа), см. `lib/money.ts`.
- Каждое действие с деньгами и складом пишется в журнал (`lib/audit.ts`).
- Пин-коды хранятся как bcrypt-хеши; кассир выходит сам через 15 минут бездействия.
